# ОСВЕД — приёмка реального сбора источников

Дата: 2026-10-22. Этап 1 дорожной карты — проверить получение и запись
публикаций YouTube и GitHub до включения автоматической новостной рассылки.

## Что теперь видно в карточке источника

- never_checked — источник сохранён, но попытки опроса не зафиксированы.
- collected — последний запуск добавил новые публикации.
- no_new_items — опрос обнаружил материалы, но ничего нового не записал.
- empty — успешный опрос без новых публикаций.
- error — последний запуск завершился ошибкой, включая причины и backoff.
- running, paused, history_only — идёт сбор, приостановлен, исторический источник.

Статусы берутся из `source_runs`, `source_health` и `source_items` SQLite.
Просмотр не выполняет сетевые запросы, не тратит квоту и не меняет базу.

## Read-only диагностика на Hermes

В GitHub Actions `OSVED administration` уже выполняется `news-readiness`
после успешного SSH-деплоя. Новое поле `source_collection` показывает
`active_status_counts`, `by_platform` и ограниченный список ошибок.
Оно помогает отдельно оценить YouTube и GitHub без вывода токенов.

## Дальнейшая приёмка

1. Выбрать по одному импортированному каналу YouTube и репозиторию GitHub
   с недавно выпущенными публикациями.
2. Проверить их состояние в разделе «Источники».
3. Отдельно выполнить ограниченный бесплатный опрос этих `source_id`
   существующим сборщиком; сначала подтвердить бесплатность выбранного
   адаптера. Не включать расписание, платные вызовы и отправку автоматически.
4. Проверить `items_seen`, `items_inserted`, ошибки, запись новых
   `source_items`. Повторный опрос не должен дублировать материалы.
5. После нескольких успешных циклов проверить отдельный путь:
   публикация → событие → проверенная карточка → доставка.

Последний подтверждённый серверный read-only отчёт до этой работы:
`source_items=47`, `candidate_events=26`, `valid_cards=0`,
`sent_deliveries=0`, `schedule_enabled=null`,
`card_provider.configured=false`. Это исторический снимок, не новый тест.
