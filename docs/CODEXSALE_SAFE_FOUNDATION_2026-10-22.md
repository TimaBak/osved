# Codex Sale — безопасное изолированное основание (2026-10-22)

## Статус
Это **не переключение production** и **не доказательство реальной оплаты/ответа модели**. Ветка переносит минимальные независимые файлы из draft PR #1 без изменений старого OpenRouter-пайплайна.

- `app/llm/codexsale.py`: ограниченный API origin, `GET /models`, chat/responses, безопасная классификация HTTP/transport ошибок без журналирования токена.
- `app/llm/model_registry.py`: единый namespace `codexsale.model.<task>` в существующем runtime-settings repository; выбранная модель не подключена к действующим генераторам.
- `tests/test_codexsale_foundation.py`: unit проверки, включая запрет использования текстового каталога для audio/image.
- Текстовые идентификаторы и возможности моделей здесь **предварительные**, подтверждаются живым `/models` и отдельной проверкой endpoints. Коэффициент тарифа провайдера нельзя трактовать как USD.
- **Никакие платные запросы, миграции БД или server env изменения эта ветка не запускает.**

3. Спроектировать server-side резервирование суммы до вызова, idempotency, фиксацию usage/uncertain charge и ручной opt-in OpenRouter; пока этого нет, production routing не менять.

5. Не объединять старый PR #1 (50 файлов, конфликтует с `main`) автоматически.
