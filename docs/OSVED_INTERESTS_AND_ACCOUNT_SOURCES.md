# ОСВЕД — персональные источники, интересы и рекомендации

Статус: **V1 реализуемое ядро + план дальнейших подключений** (2026-10-22).
Сверять с текущим `main` и `docs/OSVED_PRODUCT_VISION.md`; планы не заменяют фактические функции.

## Цель

Пользователь определяет свои интересы, источники и уровень глубины. ОСВЕД ищет,
сводит, фильтрует, проверяет, объясняет, **почему показал публикацию**, и
постепенно улучшает рекомендации через прозрачную обратную связь.
Непроверенный сигнал никогда не становится проверенной новостью из-за рейтинга.

## Внедряемый V1: честная персонализация без платного AI

- **Приоритет тем**: от -3 до +3; ноль нейтрален.
- **Оценка карточки**: больше похожего, меньше похожего, не моё, уже знаю,
  нужен глубокий разбор, следить за темой, сбросить оценку.
- **Одна актуальная оценка на материал**: новый выбор заменяет старый, двойные
  клики не усиливают профиль бесконечно.
- **Объяснимое ранжирование**: ручной вес + ограниченный сигнал реакций той же
  темы + выбор для конкретного материала. Сохранять изначальный порядок при
  одинаковом рейтинге. Сигналы и проверенные статьи остаются в разных разделах.
- **Приватность и контроль**: таблицы SQLite с метками времени, owner-only API,
  CSRF, кнопка полного сброса весов и оценок; избранное и заметки не удаляются.
- **Проверяемость**: тесты сортировки, защиты, перезаписи реакции, сброса;
  мобильный браузер нажимает реальные кнопки и видит обновлённый выбор.

Эта версия **не** пытается определить характер, эмоции или политику пользователя.
Отсутствие оценки — нейтральное состояние. Игнорирование карточки в V1 не
считается отрицательной реакцией. Клик по ссылке и сохранение закладки не
приравниваются к одобрению — нужен явный сигнал.

## Подключение аккаунтов и подписок: порядок

| Канал | Стартовый вариант | Авторизованный вариант | Особенности |
|---|---|---|---|
| RSS/Atom | публичный URL | не требуется | доверие, частота, повторы |
| Reddit | публичные сабреддиты/поиск; уже есть адаптер транспорта | официальная авторизация **при доступных scope/API** или импорт списка сообществ | не просить пароль, соблюдать условия и лимиты |
| YouTube | URL канала/видео и публичные фиды | официальный OAuth с разрешением **только на чтение подписок**, если доступен | отдельный отзыв токена, лимиты API |
| GitHub | публичные релизы/репозитории; коллектор уже есть | OAuth/GitHub App с минимальными правами для stars/following/watches при наличии доступа | не давать доступ к коду или записи без нужды |
| X | публичные авторы/списки; отдельный транспорт уже есть | только разрешённый тарифом/API OAuth либо импорт пользовательского списка | API может быть платным/ограниченным |
| Telegram | публичные каналы, настроенные сборщики | разрешённая пользовательская авторизация только с отдельным защищённым хранилищем | нельзя экспортировать или передавать session-string через интерфейс |
| Hacker News | публичный API | обычно не нужен | сигнал экспертов, не фактчекинг |
| arXiv/Crossref/OpenAlex | публичные метаданные/фиды | обычно не нужен | сохранить DOI, авторство, версию, даты |
| Сайты и личные PDF | URL / явная загрузка | только с согласия владельца | безопасность парсинга, удаление и поиск |

В V1 **не реализованы личные OAuth-коннекторы и импорт подписок**.
Не копировать cookies, session-string, пароли соцсетей в SQLite или GitHub.
OAuth-ключи хранить шифрованными, разграничивать `refresh/access`, продумывать
отзыв доступа, минимальные scopes и видимый журнал синхронизации.
Каждое подключение проходит право на чтение, тест квоты, дедупликацию и политику
хранения контента до включения.

## Единая модель подписок

`source_account` (провайдер/owner/scopes/expiry/status) →
`subscription` (account/provider/external_id/name/topic/mute/poll_interval) →
`source_item` (дата/original_url/автор/license/lang/fingerprint) →
`event` (кластер публикаций + подтверждения) →
`editorial_card` (проверенный материал + ссылки) →
`feedback` (смысловая оценка) →
`topic_profile` (прозрачный вес).

Одна публикация может затрагивать несколько тем; V1 использует одну
консервативную тему из уже существующего folder-классификатора.
В V2 перейти к тегам с подтверждаемыми объяснениями, не проставлять
«интерес к теме» по случайному совпадению слова.

## Режимы ОСВЕД

1. **Главное для меня**: небольшой высокоприоритетный поток, без дублей.
2. **Слежу**: выбранные темы, авторы, проекты, компании, репозитории.
3. **Открытия**: отдельная доля неожиданных материалов, без профильного пузыря.
4. **Исследование**: долгие статьи, научные источники, мнение разных сторон,
   фактчекинг, цитирование и таймлайн.
5. **Не пропустить**: критичные изменения подтверждённых объектов, даже если
   общий интерес к теме низок.
6. **Тихий режим**: только ежедневная или недельная сводка, без лишних push.

На главном экране объяснять «почему это показано» и «чего ещё не хватает».
При низком объёме наблюдений не выдавать топ за статистический прогноз.
Проверенные новости и непросмотренные сигналы по-прежнему разделены.

## Очередь разработки

- **P0/V1**: пользовательские реакции, приоритеты тем, ранжирование и объяснение
  в вебе; сохранение и сброс, тесты и deploy.
- **P1**: унифицировать реакцию в Telegram и вебе (один словарь сигналов и
  аудит), синхронизировать мобильные и десктопные настройки;
  сохранять контекст рекомендации при уведомлениях.
- **P2**: визуальный редактор подписок: RSS/URL, GitHub/Reddit public,
  импорт списков и просмотр статуса опроса.
- **P3**: по одному официальному OAuth-подключению с подтверждёнными read scopes,
  отдельными токенами и кнопкой «отключить и удалить».
- **P4**: полноценный русский AI-редактор с цитатами, проверкой, ограничениями
  стоимости, рекомендациями на основе смысла, а не только названия темы.
- **P5**: прогноз интересов, карта знаний, временные профили, сравнение
  перспектив, открытие новых направлений и персональные исследовательские агенты.

Проверка качества рекомендаций: частота «Не моё», осмысленное чтение, доля
повторов, разнообразие источников, свежесть и количество подтверждённых фактов.
Не оптимизировать только клики или время в приложении.
