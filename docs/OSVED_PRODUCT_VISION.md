# ОСВЕД — стратегический вектор продукта (2026-10-21)

## Миссия
Персональная информационно-аналитическая платформа: сама находит, проверяет, осмысляет и доставляет важную информацию, учится на прозрачной обратной связи, превращает материалы в исследования и полезные артефакты.

ОСВЕД — не только новостной Telegram-бот и не только чат. Один backend и единые данные для Telegram, Telegram Mini App и веб-кабинета `osved.tima.biz`.

## Продуктовые контуры
1. **Источники**: RSS/Atom, сайты, Telegram, GitHub, YouTube, X, Reddit, официальные и сторонние API. Реестр источников, расписание, доступность, доверие, квоты, backoff, диагностика.
2. **Информационное ядро**: нормализация, извлечение, дедупликация, события, связанные публикации, происхождение данных, хронология, SQLite сейчас; масштабирование при необходимости.
3. **Аналитический конвейер**: факты с доказательствами, противоречия, независимые источники, контекст, новизна, релевантность, проверка качества, короткая карточка, глубокий разбор. Не выдумывать факты, отмечать неподтверждённые выводы.
4. **Персонализация**: интересы/подтемы/компании/авторы, стоп-темы, избранное, теги, папки, оценка полезности, объяснимые рекомендации и контроль приоритетов.
5. **Telegram**: лента и push, карточки и быстрые действия, управляемые уведомления, переход в кабинет. Единая семантика кнопок, красивые Unicode fallback и проверенные custom Telegram emoji IDs (например, tgiosicons).
6. **Веб**: OSVED Intelligence Dashboard, тёмный лаконичный технологичный дизайн, квадратные информационные модули, плотная типографика, адаптивность. Разделы: обзор, моя лента, радар, аналитика, избранное, медиалаб, источники, настройки. Не делать чат главным интерфейсом.
7. **Авторизация**: Telegram login / Mini App initData с серверной проверкой, сессии, owner allowlist, безопасные настройки и права на приватные материалы.
8. **Медиалаб**: YouTube-ссылка → доступные субтитры или разрешённая транскрипция → короткое и расширенное смысловое резюме → PDF с источником, таймкодами и контекстом. По запросу: текст для поста/видео, изображения и обложки с маркировкой AI, библиотека результатов.
9. **Модели/затраты**: Codex Sale как целевое направление, реальная верификация API и моделей. Разделение моделей по задачам, лимиты, прозрачные расходы, кэширование результатов. Не приравнивать коэффициенты моделей к USD ценам.
10. **Эксплуатация**: CI→CD→SSH→Hermes→Docker→health, резервное копирование данных, проверка точного SHA, rollback при совместимости, логи и статусы. Безопасный staged rollout источников и платных операций.

## Приоритет и приёмка
- **P0 Рабочий backend и выпуск**: успешный CI/deploy наблюдён, контейнер healthy, SHA указан; диагностика реальных источников и ограниченного исследовательского цикла.
- **P1 Новости**: один верифицированный материал→карточка→доставка владельцу без дублей и неконтролируемой стоимости; затем три последовательных цикла; после — безопасное расписание.
- **P2 Интересы и Telegram**: выбор тем, реакции, сохранения, тегирование, управляемые уведомления, понятная иконографика, корректная работа callback.
- **P3 Веб API и кабинет**: Telegram-auth, общие данные, feed/detail/favorites/tags/topics/settings; HTTPS на osved.tima.biz; responsive dashboard, тест на ПК и мобильном.
- **P4 Медиалаб**: короткие/развёрнутые PDF по видео, тексты, опциональная генерация изображений, соблюдение прав на контент.
- **P5 Полировка**: рекомендации с объяснением, сигналы/дайджесты, мониторинг качества источников, тесты восстановления.

## Правила продукта
- Не путать тестовый /start с готовностью новостной ленты; показывать честный статус, onboarding и путь к настройке.
- Не считать CI Success подтверждением новости, входа, внешнего API или сайта.
- Не считать отсутствие откликов доказательством отсутствия интереса; предоставлять ручные настройки.
- Приоритизировать качество и полезность: один доказанный материал лучше десяти выдуманных.
