## Что пользователь хочет
ОСВЕД (OSVED) — Telegram-first персональная информационно-аналитическая система, единый backend и веб-кабинет `osved.tima.biz` / Telegram Mini App. В идеале работает самостоятельно: выбирает источники, собирает и дедуплицирует новости, проверяет факты, связывает публикации в события, оценивает важность и релевантность, объясняет, доставляет; учится на прозрачной обратной связи. Реальный product, не «бот готов принимать фидбэк».

### UX и функциональные требования
- При `/start`: работающий onboarding и главное меню: моя лента, интересы/темы, радар, избранное, видео/медиалаб, настройки. Если контента нет — честный статус и понятный следующий шаг. Отсутствие пользовательских кнопок — известная проблема.
- Лента: короткая карточка → подробный разбор/полный аналитический материал; первоисточники, факты, контекст, ссылки, отсутствие дублей, управляемое расписание и уведомления.
- Выбор тем, каналов и источников; избранное, папки, теги, ручная корректировка приоритетов, реакции «полезно/не моё», объяснимые рекомендации. Поддержать быстрые Telegram inline callback и синхронизацию с веб-кабинетом.
- Стиль кнопок и эмодзи: единый Apple/Telegram-подобный визуальный язык; ранее упоминался набор `https://t.me/addemoji/tgiosicons`. Custom emoji только с валидными ID и поддержкой Telegram API; Unicode fallback.
- Веб: красивый тёмный технологичный dashboard с квадратными/плиточными карточками и хорошей типографикой (не «чат в браузере»); overview, feed, radar, analytics, bookmarks, media lab, sources, settings; responsive. Требуется Telegram auth / Mini App с серверной проверкой initData, безопасность сессий. Истинные старые картинки дизайна не доступны этому handoff — запросить только если необходимы для точной визуальной реализации.
- Медиалаб: ссылка на YouTube → доступные субтитры/разрешённая транскрипция → краткий смысловой PDF + расширенный аналитический PDF с деталями, контекстом, таймкодами, выводами; текст для поста и видео; AI-обложки/иллюстрации по желанию, обозначать генерацию; соблюдать права авторов.
- Модели: проектный курс — Codex Sale; провайдер/ключи/поддержку моделей проверять по коду и безопасной серверной конфигурации, не придумывать. Экономия токенов, кэш, бюджеты и quality gates.
