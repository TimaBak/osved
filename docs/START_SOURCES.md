# OSVED — запуск источников и актуальные ограничения

## Почему лента пуста

На Hermes диагностировано 0 источников, 0 событий, 0 карточек. В репозитории файл `config/sources.yaml` содержит `version: 1\nsources: []`. Пока он пуст и новые каналы не добавлены, радар не может собрать новости, а недельная аналитика и биографии не получают материал. Наличие API-ключей не создаёт источники автоматически.

## Что поддерживает существующий код

| Источник | Где настраивается | Доступ |
| --- | --- | --- |
| Telegram-каналы | Отправить ссылку `t.me/...` или `@канал` боту; управление `/tgchannels` | Для прямого чтения Telegram может понадобиться `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и авторизованная сессия Telethon. В конфигурации Hermes `telegram_reader=false`. |
| YouTube-каналы | Отправить ссылку на канал боту; управление `/channels` | Публичные каналы; получение транскриптов отдельных видео через Monid. |
| RSS | `config/sources.yaml`, затем `osved sync-sources` | Открытая RSS-лента обычно без логина. |
| Reddit | `config/sources.yaml` | Возможность/учёт авторизации зависит от конкретного коллектора и политики доступа. Не обещать сбор без проверки. |
| X/Twitter | `config/x-authors.yaml` и `osved collect --kind x` | В CLI сбор X использует Monid; наличие ключа не гарантирует доступ к каждому профилю. |

Список форматов и полей YAML следует сверять с реальным загрузчиком `load_source_registry`, прежде чем вручную редактировать конфигурацию.

## Операции

- `osved sync-sources` — синхронизирует YAML-источники с базой SQLite.
- `osved doctor` — проверяет конфигурацию и текущие счётчики.
- `osved collect --help` — параметры запуска сбора, включая тип источника.
- `/sources` в Telegram — включение/пауза уже зарегистрированных источников.

Состояние после сборки Docker не означает, что включён фоновый планировщик. Нужна отдельная проверка запуска сбора и конвейера карточек по фактическим задачам/логам.

## План подключения

1. Добавить несколько конкретных публичных каналов YouTube и Telegram боту; для RSS заполнить конфигурацию после проверки YAML-схемы.
2. Проверить, появились ли источники в `osved doctor` и `/sources`.
3. Выполнить диагностический сбор с лимитами, не запуская платную генерацию в цикле.
4. Проверить `source_items`, `events`, карточки и очередь доставки; только потом включить расписание.
5. Отдельно установить Telegram Reader, если прямое чтение выбранных каналов требует пользовательской сессии.

## Интерфейс

`/start` и `/menu` открывают главное меню. Статус/радар, каталог источников и выбор формата видео должны быть доступны кнопками. Для полного отказа от команд ещё нужны сценарии добавления источников, диагностики и управления расходами.
